# Weather app

this is a weather application build using html, css and JS. this weather app fetches weather info of usere requested city and when user refresh last searched city weather info persist.

## Featuers

- Show weather info acording to user request.
- User last searched weather info persist
- dropdown option profided for 5 last searched cityes.
- loading and error message
- clean and maintainable code

## How to run

Open index.html file with live server.
